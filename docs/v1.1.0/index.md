# Overview

<p style="font-size:1.15rem; color: var(--vp-c-text-2); margin-bottom: 24px;">A file manager and media picker for Laravel and Filament.</p>

<p>In Nepali, <strong>Sanchaya (सञ्चय)</strong> means the act of gathering or amassing something valuable over time. This package follows that idea: your files are gathered in one place, indexed in your database, and managed with a familiar Filament experience.</p>

 <div class="cards">
    <div class="card">
        <h4>Full File Manager</h4>
        <p>Folder tree, grid/list views, cursor pagination, toolbar with search &amp; filters.</p>
    </div>
    <div class="card">
        <h4>SanchayaPicker Field</h4>
        <p>Drop-in Filament form field for single or multi-file selection with group-based persistence.</p>
    </div>
    <div class="card">
        <h4>Multi-Disk</h4>
        <p>Switch between any configured Laravel filesystem disk at runtime.</p>
    </div>
    <div class="card">
        <h4>Authorization</h4>
        <p>Laravel Gate policy controls who can rename, move, copy, delete, or download.</p>
    </div>
    <div class="card">
        <h4>Model Attachments</h4>
        <p>Polymorphic group-based attachments via the <code>HasSanchayaFiles</code> trait.</p>
    </div>
</div>

<h3>Requirements</h3>
<ul>
    <li>Filament <code>^5.0</code></li>
</ul>
