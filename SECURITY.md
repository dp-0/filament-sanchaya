# Security Policy

## Supported versions

Security fixes are provided for the latest released version of Filament Sanchaya. Please update to the latest release before reporting an issue that may already be fixed.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to [dineshphuyel20@gmail.com](mailto:dineshphuyel20@gmail.com). Include the affected version, steps to reproduce, and the potential impact. Do not open a public GitHub issue for an unpatched vulnerability.

We will review the report and coordinate a fix and disclosure with you. Once a fix is available, we will publish a release and acknowledge the report if you would like to be credited.
